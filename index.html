Setup Before You Begin Read first
0/4 ▼
Key info: Platinum requires 3 playthroughs with the same character. Each ending unlocks soul-bound items needed for collectors. Estimated time: 80–100 hours. Difficulty 7/10 (6/10 with duplication exploit).
Disable automatic PS+ save sync
PS5 Settings → Saved Data → Saved Data (PS5) → Sync Saved Data → disable auto sync. This prevents cloud from overwriting your manual backups.
Critical
Learn the Duplication Exploit (optional but recommended)
Co-op partner drops Vigor Skulls → you consume them to level fast. Back up save → drop items to friend → redownload save → repeat. Cannot duplicate: spells, armour, gestures, quest items, boss materials.
Time Saver
Read the All Endings Guide before starting
Understanding all three endings (Adyr / Radiant / Umbral) upfront prevents costly mistakes. Each ending requires specific beacon interaction behavior throughout the run.
Critical27 Missables
Read the All-in-One Collectible Guide
Familiarise yourself with all collectible types: weapons, armour, rings, pendants, spells, umbral eyes, stigmas, gestures, ammo, throwables. Know which items require farming from enemy drops.
